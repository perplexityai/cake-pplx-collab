# cake-pplx-gqa

Cake `gqa` training kernels. Public modules:

- `cake_pplx.cake_gqa_det_train`
- `cake_pplx.cake_gqa_nondet_train`

Install this family alone, pinned to a commit:

```bash
pip install "cake-pplx-gqa @ git+https://github.com/perplexityai/cake-pplx-collab@<sha>#subdirectory=kernels/gqa"
```

The repository rules are in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
