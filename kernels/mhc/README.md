# cake-pplx-mhc

Cake `mhc` training kernels. Public modules:

- `cake_pplx.cake_mhc_det_train`
- `cake_pplx.cake_mhc_nondet_train`

Install this family alone, pinned to a commit:

```bash
pip install "cake-pplx-mhc @ git+https://github.com/perplexityai/cake-pplx-collab@<sha>#subdirectory=kernels/mhc"
```

The repository rules are in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
