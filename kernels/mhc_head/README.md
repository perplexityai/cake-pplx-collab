# cake-pplx-mhc-head

Cake `mhc_head` training kernels. Public modules:

- `cake_pplx.cake_mhc_head_det_train`
- `cake_pplx.cake_mhc_head_nondet_train`

Install this family alone, pinned to a commit:

```bash
pip install "cake-pplx-mhc-head @ git+https://github.com/perplexityai/cake-pplx-collab@<sha>#subdirectory=kernels/mhc_head"
```

The repository rules are in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
