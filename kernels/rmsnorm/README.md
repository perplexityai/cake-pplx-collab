# cake-pplx-rmsnorm

Cake `rmsnorm` training kernels. Public modules:

- `cake_pplx.cake_rmsnorm_det_train`
- `cake_pplx.cake_rmsnorm_nondet_train`

Install this family alone, pinned to a commit:

```bash
pip install "cake-pplx-rmsnorm @ git+https://github.com/perplexityai/cake-pplx-collab@<sha>#subdirectory=kernels/rmsnorm"
```

The repository rules are in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
