# cake-pplx-gated-act-mxfp8

Cake `gated_act_mxfp8` training kernels. Public modules:

- `cake_pplx.cake_gated_act_mxfp8_det_train`

Install this family alone, pinned to a commit:

```bash
pip install "cake-pplx-gated-act-mxfp8 @ git+https://github.com/perplexityai/cake-pplx-collab@<sha>#subdirectory=kernels/gated_act_mxfp8"
```

The repository rules are in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
