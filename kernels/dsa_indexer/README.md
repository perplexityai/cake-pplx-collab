# cake-pplx-dsa-indexer

Cake `dsa_indexer` training kernels. Public modules:

- `cake_pplx.cake_dsa_indexer_det_train`
- `cake_pplx.cake_dsa_indexer_nondet_train`

Install this family alone, pinned to a commit:

```bash
pip install "cake-pplx-dsa-indexer @ git+https://github.com/perplexityai/cake-pplx-collab@<sha>#subdirectory=kernels/dsa_indexer"
```

The repository rules are in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
